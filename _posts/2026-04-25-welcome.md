# 블로그 시작

이 저장소는 GitHub Pages에서 Just the Docs 테마로 배포됩니다.

앞으로 이곳에 개발 기록과 정리한 내용을 계속 추가하면 됩니다.

## 새 글 작성 방법

1. `_posts` 폴더에 새 Markdown 파일을 만듭니다.
2. 파일 이름은 `YYYY-MM-DD-title.md` 형식을 사용합니다.
3. 상단 front matter에 제목과 날짜를 넣습니다.
4. `main` 브랜치에 푸시하면 GitHub Actions가 페이지를 다시 빌드합니다.
